# Sistema Acadêmico – Aula 10 (DOM e Eventos)

Projeto da disciplina Programação Web I (UNIVEST). Abra `index.html` no navegador, sem necessidade de servidor.

- **Dashboard** (`index.html`): totais e alternância "apenas ativos".
- **Alunos** (`alunos.html`): lista, busca por nome, filtro por status, cadastro, detalhes, remoção e atualização do dashboard.
- **Cursos, matrículas e usuários**: listas e formulários renderizados via DOM.

Os dados ficam só em memória e são reiniciados ao recarregar a página. Respostas teóricas em `RESPOSTAS.md`.
